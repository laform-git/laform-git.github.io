# Study Library (notes for Claude)
- What this repo is: Oscar's public Study Library website (GitHub Pages: https://laform-git.github.io/). Each study site lives in its own folder (e.g. claude-tips/, aquinas/, bikman-biology/); the home page index.html lists them from sites.json.
- To add a site: put it in its own folder, add an entry to sites.json (name, section, path, blurb, langs, status), then check that it loads on the live site.
- Related work: LAFORM's FileMaker code lives in the private repo laform-git/laform-estimate (FileMaker Server runs on the office Mac mini). Notes and logs live in Oscar's Dropbox, not in this repo.
- Habit: pull = OPEN (start of a session), push = CLOSE (end of a session). GitHub holds the code; Dropbox holds outputs and notes only.
- This repo is PUBLIC: never put passwords, server addresses, client names or private notes here.
