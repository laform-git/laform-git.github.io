Why use projects?

A chat by itself

  • A new chat starts blank
  • You explain your situation again
  • Nothing is shared with other chats
→

A chat in a project

  • Reads the project's instructions and files first
  • Already knows your situation
  • Same rules in every chat

Example: put "I have a bad knee" in the Personal project once, and every chat in it knows. Put your invoice format in Business once, and every chat there uses it.

Instructions or a log?

Project instructions

The fixed rulebook. You write it, and it stays the same until you change it.

Dropbox log

The evolving memory. Chats read it and add to it, so one chat can see what another did.

How to wire it: the log lives in Dropbox, not in the project. The project only holds one router line that points to it. Put this in the project's instructions:

Before answering, read the file "Personal Log" in my Dropbox folder. When we finish, add a dated entry that summarizes what we did.

This works when Claude can reach your Dropbox (connector turned on). If it can't save to the file, ask it for the entry and paste it into the log yourself.

Warning: don't mix topics in one chat

One chat for everything

  • Knee pain, then an invoice, then a recipe
  • Claude's attention spreads across unrelated history
  • Answers get vaguer and pull in details that don't belong
  • You can't find it later: searching "invoice" returns a grab-bag
→

One topic per chat

  • Focused answers
  • Easy to find by name or search
  • Lives in the right project
