CLAUDE CLASS · CLAUDE-09

Claude puede hacer más de lo que crees

12 funciones que casi nadie usa, explicadas en palabras sencillas.

El mapa: todo se conecta con Claude
← desliza para ver todo el mapa →

Claude está en el centro. Cada cuadro es un poder extra que se conecta con él. No necesitas todos: escoge los que te sirvan en tu día. Abajo están los mismos cuadros en tres grupos. Entre paréntesis va el nombre que verás en la app, en inglés.

1 · En cada chat2 · Trabaja por ti3 · Para quienes programan
1 · En cada chat
📁

Proyectos (Projects)

Una carpeta para un tema. Todos los chats de adentro comparten los mismos archivos e instrucciones, así que nunca explicas dos veces.

Prueba: crea un proyecto llamado "Impuestos" y sube los papeles del año pasado.
🧊

Artefactos (Artifacts)

Claude construye algo real que puedes guardar: una página, una gráfica, una pequeña app o un documento. Se abre junto al chat y puedes compartir el enlace.

Prueba: "Hazme un menú semanal que pueda ir palomeando."
🧠

Memoria (Memory)

Claude recuerda datos útiles de ti de chats anteriores: tu trabajo, tu estilo, en qué estás trabajando. Puedes verla, editarla o apagarla en Configuración.

Prueba: "Recuerda que escribo en español de México."
💭

Pensamiento adaptable (Adaptive Thinking)

Claude decide cuánto pensar. Una pregunta rápida recibe una respuesta rápida; un problema difícil recibe más tiempo para razonar antes de contestar.

Prueba: no hay nada que encender. Para problemas difíciles, dile "tómate tu tiempo y piénsalo bien".
🛠️

Habilidades (Skills)

Recetas guardadas para trabajos que repites. Claude sigue los mismos pasos cada vez, como una lista que nunca olvida.

Prueba: "Convierte la forma en que hicimos este reporte en una skill."
✏️

Diseño (Design)

Claude hace piezas visuales que puedes ver y editar: carteles, presentaciones, pantallas de apps, volantes. Las cambias platicando.

Prueba: "Diseña un volante para la venta de fin de semana de mi panadería."
2 · Claude trabaja por ti
📅

Tareas programadas (Scheduled Tasks)

Das una instrucción y Claude la hace solo, más tarde o todos los días, aunque no estés.

Prueba: "Cada lunes a las 8, mándame los pedidos de la semana."
💻

Tu computadora

Cuando tu chat está vinculado a tu computadora con la app de escritorio de Claude, Claude puede abrir, ordenar, renombrar y editar archivos en las carpetas que tú permitas, y usar apps de esa computadora.

Prueba: "Cámbiale el nombre a todas las fotos de esta carpeta según la fecha."
🌐

La web

Para buscar información, Claude busca y lee páginas web dentro del chat. No necesita navegador.

Para hacer cosas en un sitio (dar clics, llenar formularios, iniciar sesión), Claude usa un navegador, de una de dos formas:

① Tu navegador: tu propio Chrome, con la extensión Claude in Chrome y tus propias cuentas.
② El navegador de Claude: el que viene en la app de escritorio de Claude, con sus propias cuentas.

Prueba: "Busca tres vuelos a Cancún de menos de $5,000 y hazme una lista."
3 · Para quienes programan
⌨️

Claude Code

Claude escribe y arregla programas por ti, trabajando directamente en los archivos del proyecto.

Prueba: "Hazme una página web sencilla para mi negocio."
📄

CLAUDE.md

Una nota que dejas en la carpeta de un proyecto y que Claude lee primero, cada vez: las reglas, los nombres, cómo te gusta que se hagan las cosas.

Es como: las instrucciones de un proyecto, pero para Claude Code.
⚡

Prompt Caching

Para quienes crean apps con Claude: las instrucciones largas que se mandan una y otra vez se guardan un rato, así las respuestas llegan más rápido y cuestan menos.

Quién lo necesita: programadores que usan la API de Claude. En la app no tienes que hacer nada.
Por dónde empezar
1Crea un Proyecto para lo que más haces.
2Pídele a Claude un Artefacto que vayas a guardar.
3Pásale un trabajo repetido a una Tarea programada.

Cada uno se configura en pocos minutos y te ahorra tiempo todos los días después.
