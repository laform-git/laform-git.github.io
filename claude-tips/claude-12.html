Claude Code: From Talking to Doing

A chat answers you. Claude Code does the work: on your files, your website and your apps, while you watch and approve.

In this lesson
  • What Claude Code is, and how it is different from a chat
  • Where you can use it: computer, browser and phone
  • Everything it can do, in plain words
  • How to start safely, and how to undo
The big idea

In a chat, Claude tells you what to do and you do it. In Claude Code, Claude does it: it opens the files, makes the changes, runs the steps, checks the result and shows you what changed. You stay the boss: it asks before anything important.

ChatClaude Code
What you getAn answer, a draft, a file to downloadThe job done, on your real files
Who does the stepsYou copy, paste and clickClaude does them and reports back
What it can touchWhat you paste or attachA folder you choose on your computer, or a project on GitHub
How long it worksOne answer at a timeMinutes or hours, step after step, even on its own schedule
SafetyNothing changes until you actIt asks permission before changes; you can review and undo

Simple rule: want to know something? Chat. Want something done on your files, site or apps? Claude Code.

Where it runs

🖥️ Desktop app

The easiest start. In the Claude app, open the Code tab and pick a folder. Changes show side by side so you can review them.

🌐 Browser and phone

At claude.ai/code or in the Claude phone app. It works in the cloud, so you can start a long job and check back later.

⌨️ Terminal and editors

For people who code: the Mac Terminal, VS Code and JetBrains. Same Claude Code, same powers.

It needs a paid Claude plan. Your settings and instructions follow you from one place to another.

Step by step: your first job
1Open the Claude desktop app and choose the Code tab.
2Pick a folder to work in. Start with a copy, not your only originals.
3Say what you want in plain words, with the result you expect.
4Claude shows a plan, then asks before it changes anything. Read it and approve.
5Review what changed. Not right? Say what to fix, or ask it to go back.

Mistakes to avoid

✕ Working on your only copy

Start in a copy or a folder saved on GitHub, so every step can be undone.

✕ Approving without reading

It asks before changes for a reason. Read the plan, then say yes.

✕ Vague requests

Say what "done" looks like: which pages, which folder, what to check.

✕ Passwords in files

Log in yourself in the browser when it asks. Never paste passwords into the chat or a file.

Practice (10 minutes)
  1. Open the Code tab and pick a folder with a few copied photos.
  2. Use the "Tidy a folder" recipe. Read the plan before you approve.
  3. Ask: "What did you change, and how do I undo it?"
Check yourself
You want to know how to make a menu. Chat or Claude Code?

Chat. You want an answer. Use Claude Code when you want the menu built and published for you.

Where is the easiest place to start Claude Code?

The Code tab in the Claude desktop app.

How do you give Claude Code rules it always follows?

Put them in a CLAUDE.md file in the folder. It reads it at the start of every session.

Where this is going

AI is moving from answering to doing: helpers that take a whole job, work for hours, run on a schedule and check their own work. The habit to build now: describe the result you want clearly, keep your files where every version is saved, and review before you approve.
