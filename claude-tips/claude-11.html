Notion, Claude's Long-Term Memory

A power add-on: give every chat a memory that lasts for months, not just one conversation.

In this lesson
  • Why a strong AI still gains from an outside memory
  • How one Notion page per area becomes that memory
  • The open and close habit that keeps it current
The big idea

Each Claude chat is very capable, and it works on the conversation in front of it. Connecting it to Notion adds a layer that never forgets. Notion becomes Claude's long-term memory.

📖 Open: read the page→💬 Work with full context→✍️ Close: save what changed→📖 Next chat starts there

It is an add-on that multiplies what Claude already does well. Your knowledge lives in pages you can read and edit, and it works with any AI that can read and write in Notion.

Step by step

Set up the memory

1Connect Notion to Claude (see Claude-08).
2Make one Notion page for each area of your life or work, for example Health, Faith or Business.
3Give each page three sections: Scope (what this area covers), How it operates (your rules) and Now (what is open today).
4In the project instructions, tell Claude to read that page at the start of every chat and to update Now at the end (see Claude-05).

Use it every day

1Start a chat with OPEN. Claude reads the page and tells you where things stand.
2Work as usual. Say remember or from now on when something should last.
3End with CLOSE. Claude saves what changed, so the next chat picks up from there.
Recipes to copy and paste
Project instructions
At the start of every chat, read the Notion page [page name] and tell me what is open in Now. When I say CLOSE, update Now with what changed today and keep only what is current.
Open a chat
OPEN. Read our page and tell me where we left off, in three lines.
Save something for good
Remember this from now on: [the rule]. Add it to How it operates on our page and show me the change.
Close a chat
CLOSE. Update Now on our page: what we finished, what is still open and the next step.
Mistakes to avoid

✕ One giant page

Keep one page per area. A short, current page is read better than a long history.

✕ Forgetting to close

If you don't say CLOSE, the next chat starts from the old page.

✕ History in Now

Now holds only what is current. Move old events to a log page (see Claude-06).

✕ Passwords in the page

Never store passwords or account numbers. Write only where they are kept.

Practice (10 minutes)
  1. Make a Notion page for one area with Scope, How it operates and Now.
  2. Paste the project instructions recipe into that project, with your page name.
  3. Open a chat with OPEN, do one small task, and end with CLOSE. Then open a new chat and see what it remembers.
Check yourself
Why add Notion if Claude is already powerful?

Each chat focuses on the conversation in front of it. Notion is the long-term layer that carries context from one chat to the next.

Which section holds today's open items?

Now. It is overwritten so it only shows what is current.

What should Claude do when you say CLOSE?

Save what changed to the page, so the next chat starts from there.

REMEMBER
Claude does the thinking. Notion keeps the memory. Open reads it, close writes it.
