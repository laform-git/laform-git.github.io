Previous vs New Claude

Claude used to be two separate apps. Now it is one, and the device you type on decides what it can reach.

Before: two separate apps

Chat projects

Instructions and files. Reached your online apps (like Dropbox) through connectors, text only.

Cowork

A separate app with its own setup. The only way to reach the folders on your computer.

A PDF made in chat had to be downloaded and dragged into place by hand.

Now: one combined Claude

What each way of talking can do

Phone or web

Same chat, typed away from the computer.

  • ✓ Connectors: Notion, Gmail, Calendar, Dropbox
  • ✓ Makes PDFs, web pages, Word files
  • ! Files come back as a download
  • ✕ Can't reach your computer's folders

Desktop app

Message sent from your computer.

  • ✓ Everything the phone can do
  • ✓ Saves any file straight into your folders
  • ✓ Creates and moves folders
  • ! Only in folders you added
  • ! Computer awake, app open

Voice

Talking instead of typing.

  • ✓ Connectors
  • ✓ Moves files when linked to the computer
  • ✕ Usually can't build a new PDF or file
  • → Switch to typing when a file needs making
Voice or text in the same chat

Voice and typing work in the same chat. Talk when you want to think out loud. Type when something has to be built or checked.

✓ Voice can

  • Talk a problem through and explain things
  • Search the web
  • Use your connected apps: read your email or calendar, update a Notion page, change a file
  • Move files, when the chat is linked to your computer

✕ Voice can't

  • Run code, so it can't build or test a page
  • Make a PDF, Word file or other new file
  • Take a screenshot or check how a page looks on a phone
  • Read you long tables, big code blocks or text meant to copy

Why Claude says "switch to text": the job needs building or checking. Answers in voice are also kept short so they can be spoken.

1Plan and decide by voice.
2When Claude says it needs text, open the same chat and type "Go ahead".
3Claude builds it, checks it, and shows you the result.
Four keys to remember

1 · App on the computer

The Claude desktop app, open and signed in, links your chats to that computer.

2 · Add a folder

In a chat: + → Add folder. Or use the project's Folder slot (only reaches new chats).

3 · Send from the computer

The device that sends the message decides. The same chat from your phone can't touch the computer.

4 · Connector vs folder

A connector talks to the online app, text only. A folder is plain local files, any type.

REMEMBER
One Claude. Same chat everywhere. The device you send from decides what it can reach.
